# Player contract ownership

Tilecast shares contracts where independent implementations must agree, without moving unrelated platform code into one common package.

| Contract | Authority | Consumers / conformance |
| --- | --- | --- |
| Public HTTP API | `docs/openapi/core.yaml` + plugin fragments, composed by `pluginctl` | generated Go client and TypeScript API schema; Server route parity; Redocly/oasdiff |
| Player manifest wire schemas | `packages/manifest-schema` | Server compiler, Android, Electron, Edge |
| Declarative presentation capability vocabulary | `packages/manifest-schema/presentation-capabilities.json` | generated Go/TypeScript/Rust/Kotlin tables; host profiles choose the baseline or shared-runtime set |
| Widget component capabilities | Widget manifests, generated by `widgetctl` | Player Runtime, Edge, and Android bindings; deliberately separate from the legacy declarative vocabulary |
| Shared playback behavior | `packages/player-runtime` | Electron/WPE/Android runtime conformance |
| Layout document | `packages/layout-schema` | Server, Studio, and Players |
| Edge daemon/renderer IPC | `packages/edge-protocol` | `tilecastd`, WPE renderer, migration/conformance fixtures |
| Server URL normalization/security | platform implementations + `packages/player-contracts/fixtures/server-url-policy.json` | the same fixture corpus runs in Linux, Android, and Edge tests |

## Generation

`npm run player-contracts:generate` reads the declarative capability registry and writes language-native mechanical bindings. `npm run player-contracts:check` fails when any generated binding is stale. Root `make generate` and `make generated-check` include these files.

The registry has two profiles. The **baseline** is the capability floor implemented by legacy supported Players. The **shared-runtime** profile adds capabilities implemented by the shared Player Runtime, currently `environment.time`. A host must advertise only the profile it actually runs; generation does not grant support by itself.

The Server URL fixture intentionally records only the product-wide policy floor: canonical HTTPS by default, explicit ports, LAN-scoped HTTP for private IPv4/link-local/localhost/`.local`, and rejection of public HTTP, credentials, paths, queries, fragments, and unsupported schemes. Platform-specific edge cases remain platform-owned until Tilecast deliberately versions them into this contract.

## Boundaries

This does **not** create a cross-language runtime library or FFI layer. Native process lifecycle, storage, networking, kiosk integration, media hosting, and OS APIs remain platform-owned. Widget V2 remains generated from Widget manifests rather than this registry.
