# Tilecast Edge: presentation capability matrix

This matrix compares Tilecast Edge with the Electron Linux player, feature by feature. It is the M6 parity record that [`tilecast-edge-next.md`](tilecast-edge-next.md) refers to. Electron and WPE host the shared Tilecast Player Runtime, so a feature that the runtime implements has one implementation. What differs between the two players is the host: the daemon that builds the presentation, and the capabilities that the host advertises.

Each row has one status:

| Status               | Meaning                                                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Supported            | Edge shows it as Electron does, and the named tests prove it.                                                                                    |
| Supported, different | Edge shows the same content, but delivers or times it differently. The row gives the difference and its reason.                                  |
| Planned (milestone)  | A later Edge 1 milestone owns it. Until then it is a typed incompatibility: the committed presentation stays, and the reason reaches the server. |
| Blocked on M11       | The software exists, but only physical-hardware qualification (M11) can confirm it.                                                              |
| Not in Edge 1        | Deliberately excluded, with the binding rationale.                                                                                               |
| Needs a decision     | No binding decision exists yet. None of these may remain at release-candidate time.                                                              |

"Typed incompatibility" means that `tilecastd` refuses the manifest before preparation with a `presentation_incompatible_*` code (`tilecastd/src/manifest.rs`, `incompatibilities`). The screen keeps its committed presentation.

## Content

| Feature                                                                      | Edge                 | Proof or rationale                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| ---------------------------------------------------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Image                                                                        | Supported            | `playback.rs` (`assignment_prepares_activates_and_promotes_only_after_evidence`); conformance `image-fit`; real-server script (uploaded image).                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Video, downloaded                                                            | Supported            | Conformance `video`; real-server script (uploaded video).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Video and images with `stream` delivery, and `automatic` video above 256 MiB | Supported, different | Electron fetches such items from the origin while it plays them, with no size or hash check. Edge downloads them into the content store, verifies size and SHA-256, and then plays them (`manifest.rs`, `streamed_delivery_is_a_verified_download_on_edge`). The reason is the binding Edge goal: "verifies every downloaded byte before use and never shows a partial or corrupt file" ([`tilecast-edge.md`](tilecast-edge.md) §2). The effects: activation waits for the complete download, the item also plays offline, and an item too large for the store fails preparation with the store's typed reason. |
| Native Widgets (render tree)                                                 | Supported            | Conformance `widget-compat`; `playback.rs` (`layouts_widgets_and_plugins_reach_the_renderer_as_projection_inputs`); real-server script (QR Code Widget).                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Clock, Date, World Clock and Countdown Widgets                               | Supported            | They update in place with the corrected clock and never restart the item: `projector.test.ts` (time-bound widgets); real-server script (Clock Widget).                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Web Widgets                                                                  | Planned (M11)        | They need the isolated remote-web view. Typed incompatibility `presentation_incompatible_web_widget`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| Layouts: zones, zone playlists, root Layout assignment                       | Supported            | Conformance `layout`; real-server script (published Layouts).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| Websites                                                                     | Planned (M11)        | Remote web content never runs in the trusted runtime document. Typed incompatibility `presentation_incompatible_website`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| YouTube                                                                      | Planned (M11)        | The same isolation requirement. Typed incompatibility `presentation_incompatible_youtube`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Transitions (none, fade, crossfade)                                          | Supported            | Conformance `playlist-transitions`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Item audio settings (`audioEnabled`, `volume`)                               | Supported            | They reach the shared runtime unchanged. Audio output selection is M9, and audio on real outputs is M11.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |

## Selection and timing

| Feature                                            | Edge      | Proof or rationale                                                                                                                                                                                                                                                                                                      |
| -------------------------------------------------- | --------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Direct assignment and schedules                    | Supported | `schedule.rs` unit tests; `playback.rs` (`wall_clock_steps_move_schedule_windows_and_nothing_else`).                                                                                                                                                                                                                    |
| Takeover and emergency                             | Supported | `playback.rs` (`replacement_activates_after_its_grace_period_or_at_once_for_a_takeover`, `a_takeover_during_preparation_outranks_it`); conformance `takeover`.                                                                                                                                                          |
| Quick Present ("Show now")                         | Supported | `playback.rs` (`quick_present_replaces_and_then_restores_the_assignment`). The heartbeat reports the shared `quick_present` selection source.                                                                                                                                                                           |
| Synchronized groups (Mirror)                       | Supported | `tilecastd` builds the group anchor and durations from the manifest as Electron does. `playback.rs` (`two_players_in_a_group_share_one_timeline_that_a_clock_correction_never_moves`); conformance `synchronized`; real-server script (two Edge players in one group, measured against the group epoch and each other). |
| Pending manifest activation on the shared boundary | Supported | Both hosts activate a pending manifest on the renderer's `item-transition`, which the shared timeline reports at each shared boundary. Real-server script ("after a pending manifest").                                                                                                                                 |
| Outside active hours, playback disabled            | Supported | Conformance `outside-hours` and `status-surfaces`; `playback.rs` (`outside_active_hours_the_screen_rests_until_a_takeover_outranks_it`, `configuration_and_disable_playback_change_the_screen_live_and_after_an_offline_restart`).                                                                                      |

## Span video walls

| Feature                            | Edge                 | Proof or rationale                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Span images and Layouts, unrotated | Supported            | `tilecastd` validates `canvas` and `viewport`, crops images to the panel and gives the shared projector the panel, which clips Layout zones (`spanViewport`, shared with Electron). `manifest.rs` (`span_panels_crop_images_and_reach_the_projector`); `projector.test.ts` (Span panel); conformance `span`. Malformed geometry is the typed incompatibility `presentation_incompatible_span`. |
| Span video                         | Supported            | The server makes a panel-sized video for each screen. Edge downloads and verifies it like any other video and plays it uncropped.                                                                                                                                                                                                                                                              |
| Span timing across panels          | Supported            | A Span group is a synchronized group, so the rows in "Selection and timing" apply.                                                                                                                                                                                                                                                                                                             |
| Rotated Span panels                | Blocked on M11       | Edge does what Electron does, because both use the shared runtime. The players do not agree on rotation: the shared runtime rotates an image about its top-left corner, Android rotates about the center, and the server's panel video is transposed and then scaled to the unrotated panel size. A rotated physical panel must settle the correct result before a shared fix.                 |
| Bezel compensation                 | Supported, different | The server applies bezels to Span video. No player applies them to images or Layouts; Edge is the same as Electron and Android.                                                                                                                                                                                                                                                                |
| Frame alignment between panels     | Blocked on M11       | Headless WPE cannot measure it. It needs reference DRM hardware.                                                                                                                                                                                                                                                                                                                               |

| Feature                                          | Edge         | Proof or rationale                                                                                                         |
| ------------------------------------------------ | ------------ | -------------------------------------------------------------------------------------------------------------------------- |
| Setup, pairing, idle, offline, disabled surfaces | Supported    | Conformance `setup`, `pairing`, `status-surfaces`; real-server script (fresh pairing).                                     |
| Safe mode                                        | Supported    | `playback.rs` (`safe_mode_holds_its_surface_until_exit_safe_mode_and_sync_now_reconciles`); conformance `status-surfaces`. |
| Branding on status surfaces                      | Supported    | `playback.rs` (configuration tests); real-server script (`branding.disabled_title`).                                       |
| Identify                                         | Supported    | Conformance `identify`; `commands.rs`.                                                                                     |
| Brand bug, countdown bar, alert ticker plugins   | Supported    | Conformance `plugins`.                                                                                                     |
| Noise Meter plugin                               | Planned (M9) | Capture through PipeWire. Typed incompatibility `presentation_incompatible_plugin`.                                        |

## Host features

| Feature                                               | Edge             | Proof or rationale                                                                                                                                                                                                            |
| ----------------------------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Display control (CEC, DDC, scheduled display actions) | Planned (M9)     | Scheduled display actions are the typed incompatibility `presentation_incompatible_display_control`. Display commands answer `unsupported_command`.                                                                           |
| Presentation Network                                  | Planned (M9)     | Commands answer `unsupported_command`.                                                                                                                                                                                        |
| Player updates                                        | Planned (M10)    | `install_player_update` answers `unsupported_command`.                                                                                                                                                                        |
| DRM/KMS and Wayland output, rotation of the output    | Blocked on M11   | The renderer is proven on the headless WPE platform only.                                                                                                                                                                     |
| Hardware video decode, codecs                         | Blocked on M11   | The headless image proves software decode of the conformance media.                                                                                                                                                           |
| Live preview in Studio                                | Planned (M8)     | The WPE host has the `renderer.preview` request, but answers `preview_not_implemented`. The proposal is a bounded snapshot of the runtime view that `tilecastd` sends through the ordinary preview API, with M8 telemetry.    |
| AirPlay receiver                                      | Needs a decision | Electron runs a GStreamer AirPlay receiver. No Edge milestone owns it, and the Edge architecture does not exclude it. The proposal is "Not in Edge 1", with a record in [`tilecast-edge-future.md`](tilecast-edge-future.md). |

## Renderer features

`tilecast-renderer-wpe` advertises these `renderer.ready` features (`renderer-wpe/src/protocol.c`, the same list as `manifest.rs` `profile::FEATURES`): `status-surfaces-v1`, `image`, `video`, `render-tree-v1`, `layout-v1`, `synchronized-playback-v1`, `span-viewport-v1`, `plugin.brand_bug`, `plugin.countdown_bar`, `plugin.alert_ticker`. An activation that needs a feature that the connected renderer does not report shows the "Presentation unavailable" surface and never plays partially.
