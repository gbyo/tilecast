# Tilecast Edge: presentation capability matrix

This matrix compares Tilecast Edge with the Electron Linux player, feature by feature. It started as the M6 parity record that [`tilecast-edge-next.md`](tilecast-edge-next.md) refers to, and it records the merged M1–M10 software. Electron and WPE host the shared Tilecast Player Runtime, so a feature that the runtime implements has one implementation. What differs between the two players is the host: the daemon that builds the presentation, and the capabilities that the host advertises.

Each row has one status:

| Status               | Meaning                                                                                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| Supported            | Edge shows it as Electron does, and the named tests prove it.                                                                                    |
| Supported, different | Edge shows the same content, but delivers or times it differently. The row gives the difference and its reason.                                  |
| Planned (milestone)  | A later Edge 1 milestone owns it. Until then it is a typed incompatibility: the committed presentation stays, and the reason reaches the server. |
| Blocked on M11       | The software exists, but only physical-hardware qualification (M11) can confirm it.                                                              |
| Not in Edge 1        | Deliberately excluded, with the binding rationale.                                                                                               |
| Needs a decision     | No binding decision exists yet. None of these may remain at release-candidate time.                                                              |

"Typed incompatibility" means that `tilecastd` refuses the manifest before preparation with a `presentation_incompatible_*` code (`tilecastd/src/manifest.rs`, `incompatibilities`). The screen keeps its committed presentation.

| Image                                                                        | Supported            | `playback.rs` (`assignment_prepares_activates_and_promotes_only_after_evidence`); conformance `image-fit`; real-server script (uploaded image).                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| Video, downloaded                                                            | Supported            | Conformance `video`; real-server script (uploaded video).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| Video and images with `stream` delivery, and `automatic` video above 256 MiB | Supported, different | Electron fetches such items from the origin while it plays them, with no size or hash check. ## Span video walls

| Feature                            | Edge                 | Proof or rationale                                                                                                                                                                                                                                                                                                                                                                             |
| ---------------------------------- | -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Span images and Layouts, unrotated | Supported            | `tilecastd` validates `canvas` and `viewport`, crops images to the panel and gives the shared projector the panel, which clips Layout zones (`spanViewport`, shared with Electron). `manifest.rs` (`span_panels_crop_images_and_reach_the_projector`); `projector.test.ts` (Span panel); conformance `span`. Malformed geometry is the typed incompatibility `presentation_incompatible_span`. |
| Span video                         | Supported            | The server makes a panel-sized video for each screen. Edge downloads and verifies it like any other video and plays it uncropped.                                                                                                                                                                                                                                                              |
| Span timing across panels          | Supported            | A Span group is a synchronized group, so the rows in "Selection and timing" apply.                                                                                                                                                                                                                                                                                                             |
| Rotated Span panels                | Blocked on M11       | Edge does what Electron does, because both use the shared runtime. The players do not agree on rotation: the shared runtime rotates an image about its top-left corner, Android rotates about the center, and the server's panel video is transposed and then scaled to the unrotated panel size. A rotated physical panel must settle the correct result before a shared fix.                 |
| Bezel compensation                 | Supported, different | The server applies bezels to Span video. No player applies them to images or Layouts; Edge is the same as Electron and Android.                                                                                                                                                                                                                                                                |
| Frame alignment between panels     | Blocked on M11       | Headless WPE cannot measure it. It needs reference DRM hardware.                                                                                                                                                                                                                                                                                                                               |

## Host features

| Feature                                               | Edge                 | Proof or rationale                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

Software tests: `edge-platform` display tests, `display_control.rs`, the vivid kernel CEC test in CI. See "Hardware capabilities (M9)".                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| Presentation Network                                  | Blocked on M11       | A typed client of the existing root helper `tilecast-networkd`; `provision_presentation_network` and `test_presentation_network` with the reference result codes. Tested against the real helper script with a fake `nmcli` (`tests/presentation_network.rs`). Wi-Fi hardware is M11.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| Player updates                                        | Blocked on M11       | Implemented in M10 ([`tilecast-edge.md`](tilecast-edge.md) §15). Edge releases are Player releases of the `edge` family, one for each architecture (`x86_64`, `aarch64`); Electron and Edge releases never reach the other family. A signed outer envelope binds the archive to the signed release manifest. `tilecastd` downloads the archive with the device credential, with range resume, into the content store. The root helper `tilecast-edge-update` stages an immutable side-by-side release under `/opt/tilecast-edge/<version>/`, then activates it as provisional. The candidate asks for confirmation only after 120 s of unbroken healthy evidence, and the screen reports `succeeded` only after confirmation. A guard that runs the previous release rolls back a candidate that fails, restarts repeatedly or does not confirm within 600 s, and rolls back at boot a candidate that was still provisional. Limit: a rollback after the candidate migrated `state.db` to a newer schema leaves the previous daemon in recovery mode ([`tilecast-edge-update-threat-review.md`](tilecast-edge-update-threat-review.md) §8). Tests: `edge-release`, `tilecast-edge-update` crash points, `tilecastd` `tests/updates.rs`, server integration tests, `ci/update_e2e.py` under real systemd. Update and rollback on reference hardware is M11. |
| DRM/KMS and Wayland output, rotation of the output    | Blocked on M11       | The renderer is proven on the headless WPE platform only.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| Hardware video decode, codecs                         | Blocked on M11       | The headless image proves software decode of the conformance media.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| Live preview in Studio                                | Supported, different | While Studio holds a preview lease, `tilecastd` asks the renderer for `preview.request` every 20 s (or at once on `captureNow`) and uploads the JPEG through the ordinary `POST /api/v1/player/preview`. Setup, pairing and safe mode send `failureStatus=unavailable`. The renderer takes one capture at a time with a deadline and encodes off its main loop; a capture the renderer does not answer pauses previews (10 min, doubling to 6 h), so a preview fault degrades the preview, never playback. `renderer.preview` reports the state. Tests: `a_studio_preview_lease_uploads_the_renderer_capture`, `preview.rs` unit tests, the real-server e2e `preview:` step with the WPE renderer.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| Watch live in Studio                                  | Needs a decision     | Edge answers the periodic preview lease only. It does not implement the live stream session that the Electron player serves (`apps/server/internal/livestream`). No milestone owns it.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

## Renderer features

`tilecast-renderer-wpe` still advertises historical `plugin.brand_bug` and `plugin.noise_meter` feature IDs for protocol compatibility. They are retired and the current server does not project them. Active plugin features include `plugin.countdown_bar` and `plugin.alert_ticker`; an activation requiring a missing renderer feature is unavailable rather than partially played.
