# Engineering records

This directory holds dated qualification evidence, completed technical spikes,
and implementation reviews that remain useful for traceability but are not
current architecture instructions.

Read the owning contract first. A record proves only the commit, environment,
hardware, or scenario that it names. It does not qualify a later release or a
different device automatically.

Current contracts stay in the root `docs/` directory until their domain is
reorganized deliberately. Abandoned implementation plans do not belong here;
Git history is sufficient for plans that no current contract or source comment
needs.
