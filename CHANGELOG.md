# Changelog

All notable changes to Tilecast, newest first, from the first commit on 2026-07-11 to the present.

## How to read this file

- Entries link to the pull request that made the change. The first days of work (2026-07-11 to 2026-07-13) were committed straight to `main`, so those entries name the milestone instead.
- Tilecast ships as one coordinated release from 0.26.0 on: the Server, Tilecast Edge, the Windows Player, and the Android Player share one version, and each GitHub release holds the files and notes for it. Older releases are listed in [Release lines](#release-lines).
- The notes of each GitHub release are generated from the same pull requests. This file groups them by theme and covers the periods that have no coordinated release.
- This history was rebuilt from merged pull requests and release tags. It leaves out dependency bumps and routine test, formatting, and CI repairs unless they changed how Tilecast behaves.

## 1.0.0 - 2026-11-05

The first Stable release. It covers everything merged since 0.27.0-beta.3, in 170 pull requests.

### Highlights

- **Resource-scoped access control.** Capabilities, custom roles, and Media content access ([#1675](https://github.com/gbyo/tilecast/pull/1675)), with screen authorization centralized in one explicit policy ([#1713](https://github.com/gbyo/tilecast/pull/1713)).

Weather temperature and forecast display options ([#1705](https://github.com/gbyo/tilecast/pull/1705)). Typed percent values render as ratios ([#1768](https://github.com/gbyo/tilecast/pull/1768)).
