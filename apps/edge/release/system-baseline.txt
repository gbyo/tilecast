# The Debian packages a Tilecast Edge release expects from the operating system
# (docs/tilecast-edge-sandbox-review.md, "Runtime dependency closure").
#
# A shared library that a binary in the release loads is taken from the
# operating system when its package is listed here, or is a dependency of a
# listed package. Every other library is carried inside the release
# (lib/wpe/lib) by runtime_closure.py, so the operator never installs one by
# hand. libwpe-1.0-1 is deliberately absent: the private WPE WebKit links it,
# a Debian 13 installation does not have to provide it, and the release
# carries it.
#
# One package per line. This is the list that the clean-image closure check
# installs (Dockerfile.closure) and that the Edge requirements page publishes,
# so a package added here is a new requirement for every screen.
#
