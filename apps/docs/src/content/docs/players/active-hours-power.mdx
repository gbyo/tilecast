Open **Settings** > **Active hours and power** for organization defaults, or override them for a Display Group or screen.

## Active hours

Choose a timezone, weekdays, start time, and end time.

If the end time is the same as or earlier than the start time, Tilecast treats it as an overnight window that started on the selected day.

Tilecast uses the selected timezone when evaluating the schedule, including daylight-saving changes.

Outside active hours, normal playback moves to the configured off-hours state. A Takeover can still appear when higher-priority content needs to be shown.

### Startup animation

When active hours begin, the Player plays the Tilecast startup animation before it shows content. If the display was showing the bouncing logo, the logo glides to the center first. This works with the bouncing logo, custom text, and black screen.

To turn it off, clear **Play the startup animation when active hours begin**. The setting is on by default. You can change it only when active hours are turned on.

## Power controls

<Tabs syncKey="player-platform">

<TabItem label="Android TV">

**Power Assist** uses the Android sleep and wake features available on that device. A command being accepted by the Player does not guarantee that the connected TV physically changed power state.

When playback is already open, a wake request keeps the current Player window. Applying active-hours settings does not restart that window.

</TabItem>

<TabItem label="Linux">

Linux uses [Display Control](../../screens/display-control/) for supported HDMI-CEC and DDC actions. Android-only Power Assist settings do not turn into Linux operating-system sleep commands.

</TabItem>

</Tabs>

Test the exact Player and display combination before depending on automatic power behavior.
