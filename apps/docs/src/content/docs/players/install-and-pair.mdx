Install Tilecast Player on the display, then approve it in Studio. Pairing gives the Player its own credential and adds it to your installation as a screen.

## Install a Player

Choose the guide for the display's platform. If you are not sure which platform your hardware supports, compare the [Player capability matrix](../capabilities/) first.
