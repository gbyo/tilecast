Available features can depend on the Player platform, operating-system version, firmware, adapters, and display hardware.

Use this table as a starting point, then check the actual screen in Studio before relying on a hardware-specific feature.

| Capability                                 | Android TV / Google TV / Fire TV                      | Stable Linux Player                     | Tilecast Edge                                |
| ------------------------------------------ | ----------------------------------------------------- | --------------------------------------- | -------------------------------------------- |
| Images, video, Widgets, Layouts, Schedules | Supported                                             | Supported                               | Implemented; codecs need hardware testing    |
| Prepared offline playback                  | Supported                                             | Supported                               | Implemented                                  |
| Website and YouTube content                | Supported where the Android web runtime can load it   | Supported by Electron webviews          | Not available yet                            |
| Quick Present and Takeover                 | Supported                                             | Supported                               | Implemented                                  |
| Synchronized Display Groups                | Supported                                             | Supported                               | Implemented                                  |
| Span walls                                 | Supported with current platform limits                | Supported with current platform limits  | Implemented; rotation needs hardware testing |
| Live preview                               | Supported                                             | Supported                               | Implemented                                  |
| Watch live                                 | Supported on capture-capable states                   | Supported on capture-capable states     | Not available                                |
| Player updates                             | Supported; Android/Fire OS can require local approval | Supported for the managed AppImage path | Implemented, with automatic rollback         |
| Managed Kiosk                              | Device-owner capable Android only                     | Not applicable                          | Not applicable                               |
| Android Power Assist                       | Device/firmware dependent                             | Not applicable                          | Not applicable                               |
| Accessibility Control Assist               | Android platform feature; Fire OS support differs     | Not applicable                          | Not applicable                               |
| Display Control                            | Not provided by Tilecast Player                       | HDMI-CEC and DDC/CI where reported      | Implemented; hardware dependent              |
| AirPlay receiver                           | Not supported                                         | Supported when provisioned              | Not part of Edge 1                           |
| Presentation Network                       | Not supported                                         | Supported when provisioned              | Implemented; hardware dependent              |

## Fire TV uses the Android Player

Fire TV uses the same Android Player, but Amazon firmware can behave differently from Google TV or Android TV.

Device-owner kiosk setup, accessibility settings, unattended app updates, and boot behavior can vary by model and Fire OS version. Check commissioning and the features reported by the actual device before depending on them.

## Edge is not qualified for production yet

The Edge column shows what the Edge software does. None of it is qualified on physical hardware yet, so keep production Linux screens on the stable Linux Player until a Tilecast release lists your hardware as supported.

See the [Edge capability matrix](../../edge/capabilities/) for the details and limits of each feature.
