Tilecast reports capabilities from each Player because support can depend on the platform, operating-system version, firmware, adapters, and display hardware. Use this table to choose a platform, then check the exact screen's reported capabilities before relying on a device-specific feature.

## Fire TV is still Android

Fire TV runs the Android Player, but Amazon firmware can differ from Google TV or Android TV. In particular, device-owner kiosk provisioning, accessibility settings, unattended app updates, and boot behavior can vary by model and Fire OS generation.

Treat the Player's commissioning results and reported capabilities as the final device-specific evidence.

## Edge is not stable Linux yet

The Edge column describes the development stack, not a released replacement for the AppImage Player. Use the [Edge capability matrix](../../edge/capabilities/) for its detailed preview status and qualification boundaries.
