Available features can depend on the Player platform, operating-system version, firmware, adapters, and display hardware.

Use this table as a starting point, then check the actual screen in Studio before relying on a hardware-specific feature.

| Capability                                 | Android TV / Google TV / Fire TV                      | Stable Linux Player                     | Tilecast Edge preview                 |
| ------------------------------------------ | ----------------------------------------------------- | --------------------------------------- | ------------------------------------- |
| Images, video, Widgets, Layouts, Schedules | Supported                                             | Supported                               | Preview                               |
| Prepared offline playback                  | Supported                                             | Supported                               | Preview                               |
| Website and YouTube content                | Supported where the Android web runtime can load it   | Supported by Electron webviews          | Not yet supported on Edge             |
| Quick Present and Takeover                 | Supported                                             | Supported                               | Preview                               |
| Synchronized Display Groups                | Supported                                             | Supported                               | Preview                               |
| Span walls                                 | Supported with current platform limits                | Supported with current platform limits  | Preview; still needs hardware testing |
| Live preview                               | Supported                                             | Supported                               | Preview in M8                         |
| Watch live                                 | Supported on capture-capable states                   | Supported on capture-capable states     | Not yet supported on Edge             |
| Player updates                             | Supported; Android/Fire OS can require local approval | Supported for the managed AppImage path | Not yet supported on Edge             |
| Managed Kiosk                              | Device-owner capable Android only                     | Not applicable                          | Not applicable                        |

## Fire TV uses the Android Player

Fire TV uses the same Android Player, but Amazon firmware can behave differently from Google TV or Android TV.

Device-owner kiosk setup, accessibility settings, unattended app updates, and boot behavior can vary by model and Fire OS version. Check commissioning and the features reported by the actual device before depending on them.

## Edge is still a preview

The Edge column describes current development work, not a released replacement for the AppImage Player.

See the [Edge capability matrix](../../edge/capabilities/) for more detail about the current preview and its limits.
