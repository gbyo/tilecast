Available features can depend on the Player platform, operating-system version, firmware, adapters, and display hardware.

Use this table as a starting point, then check the actual screen in Studio before relying on a hardware-specific feature.

## Fire TV uses the Android Player

Fire TV uses the same Android Player, but Amazon firmware can behave differently from Google TV or Android TV.

Device-owner kiosk setup, accessibility settings, unattended app updates, and boot behavior can vary by model and Fire OS version. Check the **Reliability** tab and the features reported by the actual device before depending on them.

## Edge depends on your hardware

The Edge column shows what Edge does. Video decoding, rotation, CEC, DDC/CI, and Wi-Fi depend on the computer and display, so run one pilot screen on your hardware before you roll Edge out.

See the [Edge capability matrix](../../edge/capabilities/) for the details and limits of each feature.

## Windows depends on your PC

Video codecs, multi-zone websites, captures, and long unattended playback depend on the PC, so run one pilot screen on the exact PC architecture you plan to use. See the [Windows installation guide](../install-windows/) for certificate requirements and platform limits.
