A **Layout** places content in fixed areas on a canvas. Use one to combine, for example, a notice, a live schedule, and a Playlist zone on one screen. You can use a published Layout as fullscreen content or add it to a Playlist.

## Create a Layout

<Steps>

1. Open **Presentations** > **Layouts**, then select **Create layout**.
2. Enter a name, choose a canvas size such as **Full HD landscape**, **Full HD portrait**, **4K landscape**, or **4K portrait**, and select **Blank canvas** or **Announcement** as the starting point.
3. Select **+** in the tool dock at the top left of the canvas, or press `A` or `/`. Choose **Media…**, **Widget…**, or **Playlist…** to open a chooser, or pick a recent item to place it right away. You can also drag a recent item onto the canvas. The Add menu also has **Text**, **Rectangle**, **Circle**, and **Line** tools: choose one, then click or drag on the canvas to draw. Press `Esc` to cancel a tool. Use **Layers** in the dock to list layers, and **Layout settings** for the canvas.
4. Arrange and resize layers on the canvas. Select a layer to edit its settings in the inspector card at the top right. A toolbar above the selection has quick actions for centering, bring to front, duplicate, lock, and delete.
5. Select **Preview** to check the current Layout, then select **Publish** or **Submit for review**.

</Steps>

If Studio cannot save an **Announcement** starting point, the Layout remains in the library. Select **Retry template setup** to finish that same Layout without creating another one. If the draft changes before you retry, setup stops and Studio asks you to review the existing Layout. Close the dialog, review that Layout in the library, then start another setup if needed.

The preview opens across the Studio window and keeps the entire canvas below its toolbar. Portrait and landscape Layouts keep their canvas proportions, including Widgets rendered inside them. The preview date starts at your local date and drives those Widgets in the organization's time zone, so an Agenda or Countdown shows the selected calendar day alongside the Layout's dynamic text.

Studio clears a Layout thumbnail when its referenced Media, Widget, Playlist, or Data Source changes. The next time an editor opens the Layout, Studio captures a new thumbnail. This does not change the Layout draft or its published revision.

The Layout library loads the first 100 matches. Search to narrow results across the library, or select **Load more** to browse later results. Presentation choosers use the same search and **Load more** controls.

The Media picker can also upload an image or video; it is added to the Media library. A Playlist zone plays independently inside the Layout. **Loop** returns to the first playable item or stops on the last one. **Corner radius** and each Playlist item's fade or crossfade transition apply in the zone. If media fails, **Fallback** shows the Layout background, keeps the last successfully loaded item, or hides the zone. The Player skips to another playable item when one is available and retries a failed final item after two seconds. A zone needs a Playlist with playable content.

Images use their item duration or the Player's default image duration. Videos start at their start offset and play to their end offset, or to the end of the media when no end offset is set. A looping zone repeats a single video from its start offset; a non-looping zone pauses its final video at its end offset. The preview uses organization playback defaults for items that use Player defaults. See the [playback settings](../administration/player-policies/) for policy controls.

If a Widget reports an error after it first renders, the Player reports a failure for that zone and keeps the Layout active so its other content can continue.

## Show changing values in text

Select a text layer and set **Content mode** to **Dynamic field**. Choose a Data Source and field, then set a format and optional fallback text. The Layout can bind text directly to one field; use a Widget when you need to display a repeating list of records. See [Data Sources](../data-sources/) and [Widgets](../widgets/).

## Limits to plan for

Tilecast allows only one visible video-capable placement or Playlist zone in a Layout, and only one placement or zone that emits audio. A Playlist zone runs independently, so don't add another video or audio source that would exceed those limits.

Layout edits remain a draft until you publish or submit them for review. Playlists can only use a published Layout, so an unpublished Layout edit doesn't change what is available for playback. Publish the Layout when the new version is ready.
