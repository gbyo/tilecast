---
title: Bulk screen changes
description: Preview a supported change across several screens before applying it.
---

Open **Screens** > **Bulk changes** when you need to make the same supported change to several screens.

Choose the target screens and an available action, then review the preview before applying it.

If a Display Group adds more screens to the target, the preview shows the actual screens that will be affected.

For Player commands, the preview also shows screens that cannot receive the command because of their platform or available features.

## Apply a bulk change

1. Select the screens or scope.
2. Choose the action.
3. Generate the preview.
4. Check the final target list, unsupported screens, and resulting change.
5. Apply the change only when the preview is correct.

A Player command that has already been collected by a Player cannot be cancelled just by changing the fleet selection afterward.

For one screen, use its detail page. If a Display Group already has a dedicated control for the action you need, use the group page instead.
