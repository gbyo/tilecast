---
title: Bulk screen changes
description: Preview one supported change across several screens before applying it.
---

Open **Screens** > **Bulk changes** when an operation genuinely needs a fleet-wide preview.

The page lets you choose the target screens and an available bulk action, then review the resolved impact before applying it. When a Display Group expands the target set, the preview shows the affected member screens rather than hiding that expansion behind the group name.

For Player commands, the preview also identifies screens that cannot receive the selected command because of platform or capability differences.

## Review before applying

1. Select the screens or scope.
2. Choose the action Studio offers for that selection.
3. Generate the preview.
4. Review the final targets, unsupported screens, and resulting change.
5. Apply only after the preview matches your intent.

A command a Player has already collected cannot be undone by changing the fleet selection afterward.

For a single screen, prefer its detail page. For a Display Group-wide display action, use the group's own controls when they provide the operation you need.
