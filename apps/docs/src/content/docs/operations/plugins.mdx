Tilecast plugins add optional features that ship with Tilecast. They are not downloaded from a third-party plugin store. Only an Owner or Administrator can install or remove a plugin.

## Install a plugin

<Steps>

1. In Studio, open **Operations** > **Plugins**.
2. Select **Explore** and choose a plugin to open its page.
3. Read the listed requirements and capabilities, then select **Install**.
4. Open the plugin's page from the installed list and configure its instances.

</Steps>

Tilecast shows installed plugins and their setup state. Some plugins need a compatible Player or network connection. For example, **Emergency Alerts** needs the server to reach the National Weather Service. A listed requirement is guidance; installation itself does not confirm that a device meets it.

The built-in catalog includes:

| Plugin                                                  | What it adds                                                               | Important limit                                                              |
| ------------------------------------------------------- | -------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| **Countdown Bar**                                       | A timed bar over normal playback.                                          | Target Players must support plugin bars.                                     |
| **Emergency Alerts** <Badge text="US" variant="note" /> | Automatic response to matching National Weather Service alerts.            | Covers U.S. alerts and needs outbound server access to the NWS service.      |
| **Forms**                                               | Submission and approval workflows whose approved records can feed Widgets. | Forms are managed from their plugin page, not from the Data Sources library. |

## Marketplace listings

When the server operator configures a marketplace catalog, **Explore** also shows marketplace listings next to the built-in plugins. Each listing names its publisher and version, states which Tilecast releases it supports, and links to its source repository. Listings come from a signed catalog the server verifies; a listing is not a security review of the package.

Tilecast cannot install marketplace listings yet, so their pages describe the listing and its state without an **Install** button. If the catalog goes stale or a refresh fails, Studio says so and keeps showing the last verified listings. An Owner or Administrator can fetch the catalog again from the notice.

See the [marketplace contract](https://github.com/gbyo/tilecast/blob/main/docs/marketplace.md) for the catalog format, signature checks, and caching behavior.

Removing a plugin is blocked while its instances or other plugin-owned resources remain. Remove those through the plugin's own page first. Removal does not delete those resources.

You can also list, install, and remove plugins with `tilecast plugin` in the [command-line interface](../../integrations/cli/). Some installed plugins add their own CLI commands and MCP tools.

See [Configure Emergency Alerts](../emergency-alerts/) for coverage, matching rules, display modes, and poll health.
