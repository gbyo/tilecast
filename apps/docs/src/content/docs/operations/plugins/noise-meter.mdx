---
title: Noise Meter (retired)
description: Compatibility information for installations that previously used Noise Meter.
---

Noise Meter has been retired. It is no longer in the Tilecast plugin catalog and cannot be installed or configured in Studio. Current Tilecast releases do not project it into new Player manifests.

Existing installations may retain their old plugin row and data. The row is inert and can be removed from **Operations** > **Plugins** without deleting its old data. Already-deployed Players may continue to send legacy fields or hold cached manifest entries; Tilecast accepts or ignores those for compatibility.

See [available plugins](../) for the features in this release.
