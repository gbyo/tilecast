---
title: Brand Bug / Watermark
description: Keep a logo, notice, sponsor mark, or label over normal playback.
---

Install **Brand Bug / Watermark** from **Operations** > **Plugins**, then create a mark from the plugin page.

A mark can use a Ready image from the Media library, text, or both. You can set its corner, size, opacity, margin, text style, optional background, date range, priority, and targets.

Targets can include all active screens, selected screens, Display Groups, or Locations.

## When marks overlap

Different corners can show different marks at the same time.

If two active marks use the same corner, the one with the higher priority is shown. If their priorities match, Tilecast uses a consistent order.

Sizes are based on the screen instead of fixed pixels, which helps the mark look similar on displays with different resolutions.

For branding on Tilecast's own setup, idle, or unavailable screens, use [Branding](../../../administration/branding/) instead.
