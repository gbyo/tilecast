:::caution[Preview requirements]
These requirements describe the current Edge development stack, not a released support promise. Hardware qualification is still in progress.
:::

## Base host

The M7 packaging work targets a Linux host with:

- Linux kernel 5.6 or later;
- systemd 248 or later;
- a 64-bit Linux environment supported by the release artifacts;
- enough local storage for the Edge release, SQLite state, and verified cached content;
- network access to the same Tilecast Server used by Studio and other Players.

Debian 12 meets the documented kernel and systemd minimums for the migration tooling. Other distributions are supported only when release notes explicitly qualify their required WPE, GStreamer, systemd, and graphics stack.

## Display stack

Edge uses WPE WebKit instead of Electron. Development exercises headless, Wayland, and DRM/KMS renderer paths. Passing the headless test suite is not the same as qualifying a physical display: connector handling, hardware decode, display ownership, restart recovery, rotation, CEC/DDC, and long-running stability require physical hardware testing.

## Before using a real screen

Check the release notes for the supported architecture, distribution, WPE/GStreamer versions, renderer backend, codecs, and display-control hardware. If the machine is not in the qualified set, keep the [stable Linux Player](../../players/install-linux/) installed.

## Network requirements

Edge uses the ordinary Tilecast Player HTTPS/WebSocket APIs. Avahi/mDNS discovery is optional; manual server entry remains available when multicast is blocked. Use HTTPS for public hostnames and local HTTP only where the normal Tilecast Player URL policy allows it on a trusted LAN.
