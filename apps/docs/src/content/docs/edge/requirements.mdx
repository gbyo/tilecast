title: Edge requirements
description: Check the Linux, display, and network requirements for Tilecast Edge, and what the release notes must confirm before you use it on a real screen.

These are the minimums the Edge software needs. A computer that meets them isn't automatically supported: a Tilecast release must list its hardware class as qualified before you use Edge on a production screen.

## Linux computer

- Linux kernel 5.6 or later;
- systemd 248 or later;
- a 64-bit `x86_64` or `aarch64` computer;
- enough local storage for Edge, its database, downloaded content, and a second release during an update;
- network access to Tilecast Server.

Debian 12 and later meet the kernel and systemd minimums. Treat another distribution as supported only when the Tilecast release notes list it.

## Display

Edge draws with WPE WebKit instead of Electron. The installer and the migration run Edge directly on the display (DRM/KMS) on the first console, without a desktop session. A computer that must keep its desktop session can't use this release of Edge.

Automated tests aren't the same as a real display. Output on real graphics hardware, rotation, connectors, hardware decoding, CEC and DDC/CI, and long unattended playback are still being qualified.

## Before you use a real screen

Check the release notes for the supported architecture, Linux distribution, display output, codecs, and Display Control hardware. If your computer isn't listed, keep using the [stable Linux Player](../../players/install-linux/).

## Network

Edge uses the normal Tilecast Player HTTPS and WebSocket connections to your server, and downloads updates only from your server, never from GitHub. LAN discovery is optional, so manual server entry works on networks that block multicast.

Use HTTPS for public hostnames. Local HTTP works only for the same trusted local addresses that the stable Tilecast Player accepts.
