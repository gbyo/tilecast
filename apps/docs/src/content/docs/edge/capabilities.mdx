---
title: Edge capability matrix
description: Compare the current Tilecast Edge preview with the stable Linux Player.
---

:::caution[Preview]
"Preview" means the feature exists in the current Edge development work or is being tested there. It does not mean the feature is supported in a stable Tilecast release.
:::

| Capability                                                   | Stable Linux Player                       | Edge preview                                               |
| ------------------------------------------------------------ | ----------------------------------------- | ---------------------------------------------------------- |
| Images and downloaded video                                  | Supported                                 | Preview                                                    |
| Native Widgets                                               | Supported                                 | Preview                                                    |
| Layouts and playlist zones                                   | Supported                                 | Preview                                                    |
| Schedules, Quick Present, Takeover                           | Supported                                 | Preview                                                    |
| Synchronized Display Groups                                  | Supported                                 | Preview                                                    |
| Span images/Layout/video                                     | Supported with current limits             | Preview; rotation/frame alignment still need testing       |
| Brand Bug / Countdown Bar / alert ticker                     | Supported where advertised                | Preview                                                    |
| Offline restart from prepared content                        | Supported                                 | Preview                                                    |
| Activity / proof of play                                     | Supported                                 | Preview                                                    |
| Live preview                                                 | Supported                                 | Preview in M8                                              |
| Remote Websites and YouTube                                  | Supported by Electron webviews            | Not yet supported on Edge                                  |
| Display Control                                              | Supported through current Linux providers | Preview in M9; hardware testing required                   |
| Presentation Network                                         | Supported                                 | Preview in M9                                              |
| Noise Meter                                                  | Supported on Linux                        | Preview in M9 host-audio work                              |
| Player self-update                                           | Supported                                 | Not yet supported on Edge                                  |
| AirPlay receiver                                             | Supported                                 | Not in the current Edge 1 plan                             |
| Android Managed Kiosk / Power Assist / Accessibility Control | Android-only                              | Not applicable                                             |

The normal Tilecast guides still apply to shared tasks such as [Activity](../../operations/activity/), [Live preview](../../operations/live-preview/), [Player commands](../../operations/player-commands/), [Display Control](../../screens/display-control/), [Schedules](../../schedules/), and [Display Groups](../../screens/display-groups/).
