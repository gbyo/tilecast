## Working in the current preview

Current automated coverage includes images, downloaded video, native Widgets, Clock/Date/World Clock/Countdown Widgets, Layouts and playlist zones, transitions, direct assignments, schedules, Takeovers, Quick Present, synchronized Display Groups, unrotated Span content, status screens, and the Brand Bug, Countdown Bar, and alert ticker plugin surfaces.

For large or stream-marked videos, Edge downloads and verifies the complete file before playback instead of promoting a partial download.

## Still being worked on

Remote Website content and YouTube still need the WPE website-isolation work. Rotated Span playback, frame alignment, graphics output, codecs, and hardware decoding also need more work or hardware testing. Player self-updates with automatic rollback work in automated testing and still need testing on real hardware.

Before moving a screen to Edge, check:

- its direct assignment and upcoming schedules;
- Layout zones and Widgets;
- synchronization or Span requirements;
- installed plugins;
- Website or YouTube content;
- Display Control and other hardware features.

The migration check also reviews compatibility before it stops the current Linux Player.

See the [capability matrix](../capabilities/) for a quick comparison with the stable Linux Player.
