Edge rejects a presentation it cannot safely render instead of partially playing it. The already committed presentation remains available when a newer manifest has an unsupported requirement.

:::caution[Preview matrix]
This page summarizes the current development stack, not a stable release support promise.
:::

## Implemented in the draft stack

Automated coverage currently includes images, downloaded video, native Widgets, time-bound Clock/Date/World Clock/Countdown Widgets, Layouts and playlist zones, transitions, direct assignments, schedules, Takeovers, Quick Present, synchronized Display Groups, unrotated Span content, status surfaces, and the Brand Bug, Countdown Bar, and alert ticker plugin surfaces.

Large or stream-marked video is deliberately prepared differently from the legacy Electron Player: Edge downloads and verifies the complete object before playback so partial or corrupt bytes are never promoted into its content store.

## Still gated

Remote Website content and YouTube need the WPE website-isolation work. Rotated Span behavior, frame alignment, real graphics output, codecs, and hardware decode need physical qualification. Edge self-updates are also a later milestone.

A missing requirement is reported as a typed incompatibility; it should not silently fall back to a weaker renderer.

Before moving a screen, review its direct assignment, active and near-horizon schedules, Layout zones and Widgets, group synchronization/Span requirements, plugins, Website/YouTube use, and hardware controls. The migration preflight also performs its own compatibility check before it stops the legacy Player.
