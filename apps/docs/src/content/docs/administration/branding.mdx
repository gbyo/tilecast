---
title: Branding
description: Set the organization branding Tilecast uses on its own Player screens.
---

Open **Settings** > **Branding** to change logos and other organization branding used by Tilecast itself.

Branding is separate from Playlist and Layout content. Changing a logo here does not edit a presentation.

Players keep the last branding settings they received if they are temporarily offline.

## Where branding appears

Tilecast can use organization branding on its own screens, such as setup, idle, disabled, or unavailable states.

Normal presentation content still uses the media, text, styles, and Widgets you added to its Playlist or Layout.

When Studio asks for a branding image, choose a Ready item from the Media library.

Organization branding applies to Tilecast's own status screens. Tilecast does not currently offer a plugin that keeps a mark over normal playback.
