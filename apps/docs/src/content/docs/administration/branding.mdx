---
title: Branding
description: Manage the organization branding that Tilecast uses in Studio and Player status surfaces.
---

Open **Settings** > **Branding** to manage organization-owned visual identity. Branding is separate from presentation content: changing a logo or status-surface treatment does not edit a Playlist or Layout.

Players receive effective branding through their normal configuration document. A disconnected Player keeps its last accepted configuration until it reconnects.

Use ready Media-library assets where Studio asks for an image. Tilecast validates branding assets before saving them rather than accepting an arbitrary file path or URL.

## Where branding appears

Branding can be used by Tilecast's own Player surfaces, such as idle, disabled, unavailable, setup, or other system-owned states. Presentation content continues to use the assets and styles authored in the Playlist, Layout, Widget, or plugin.

For a persistent mark over normal playback, use the separate [Brand Bug / Watermark plugin](../../operations/plugins/brand-bug/).
