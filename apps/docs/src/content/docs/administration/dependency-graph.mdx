---
title: Dependency Graph
description: See where Tilecast content is used before you change or remove it.
---

Open **Settings** > **System tools** > **Dependency Graph**.

The graph shows how Data Sources, media, Widgets, Layouts, Playlists, Campaigns, Schedules, Display Groups, and screens connect to one another.

## Follow a connection

Arrows point from something being used to the thing that uses it.

- Follow an arrow forward to see **where a change could appear**.
- Follow connections backward to see **what a presentation or screen depends on**.

The graph separates nearby connections from the full upstream and downstream view so large installations are easier to navigate.

Select a node to open that item in Studio. Deleted content, deleted groups and schedules, and archived screens are not shown.

## Permissions

Accounts limited to certain screens only see the screen nodes and screen-targeting connections they are allowed to access. Shared organization content can still appear when it is part of those relationships.

Use the Dependency Graph before deleting or making a large change to something that is reused in several places. Then check the item's own **Used by** section before making the final change.
