---
title: Language and regional settings
description: Change your Studio language separately from the date, time, and regional settings used across Tilecast.
---

Tilecast keeps personal Studio language separate from organization-wide regional settings.

- **Studio language** changes the interface for one person.
- **Organization regional settings** control shared date, time, timezone, and week formatting.

Changing one does not change the other.

## Studio language

Open **My Account** > **Preferences** and choose **System**, **English**, **Spanish**, or **Russian**.

**System** uses the first language from your browser that Tilecast supports. If none match, Studio uses English. A saved account preference takes priority over the browser setting the next time you sign in.

Changing the Studio language also changes the interface text direction when needed. It does not translate names, Form responses, Widget text, or other content that people entered themselves.

## Organization locale and timezone

Open **Settings** > **General** to choose the organization's locale, timezone, date and time formats, and first day of the week.

These settings are used when content does not choose its own format. For example:

- Clock, Date, and World Clock Widgets can use the organization date and time format.
- Schedules use their selected IANA timezone.
- The first day of the week can follow the locale or use a specific weekday.
- Region-aware Data Sources can use the organization locale as their default when supported.

A setting chosen directly on the content takes priority over the organization default.

## Currency

Locale changes how a currency value is displayed; it does not change which currency the value represents.

Currency fields keep their ISO 4217 code, such as USD or EUR. Tilecast formats that currency for the selected locale without converting it to another currency.

## Addresses

Locations use optional address fields such as locality, administrative area, and postal code. They do not require a U.S.-style city, state, and ZIP format.

## Documentation language

Tilecast Studio currently includes English, Spanish, and Russian interface translations. The public documentation remains English-only until translated pages can be maintained with the same accuracy as the English docs.
