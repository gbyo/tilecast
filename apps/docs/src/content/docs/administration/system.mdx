---
title: System settings and health
description: Check installation information and use the maintenance actions available in Studio.
---

Open **Settings** > **System** for server and installation information that does not belong to content or Player settings.

The maintenance actions on this page are fixed Tilecast actions. Studio does not provide a field for running arbitrary shell commands, SQL, programs, or file operations on the server.

Use the information Tilecast reports here to check server state. A browser request succeeding does not by itself prove that every server dependency is healthy.

For checks outside Studio, see the [installation readiness checks](../../installation/#check-server-readiness).

For a Player problem, use [Player commands](../../operations/player-commands/) and the screen's Activity page instead of server maintenance controls.
