---
title: System settings and health
description: Review installation-level system information and use Tilecast's bounded maintenance actions.
---

Open **Settings** > **System** for installation-level status and maintenance information that does not belong to content authoring or Player policy.

Tilecast maintenance operations are deliberately fixed actions. The settings API does not accept arbitrary shell commands, user-supplied SQL, executable names, or unrestricted file operations.

Use the page to understand the state Tilecast actually reports rather than treating a successful browser request as proof that every dependency is healthy. For server process and dependency readiness outside Studio, see the [installation readiness checks](../../installation/#check-server-readiness).

For Player-specific recovery, use [Player commands](../../operations/player-commands/) and the screen's Activity evidence instead of server maintenance controls.
