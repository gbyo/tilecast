---
title: Locations
description: Create reusable places for screens and location-based targeting.
---

Open **Settings** > **Locations** to add places such as buildings, campuses, or other sites that you want to reuse across Tilecast.

Address fields are optional. Tilecast does not require a U.S.-style city, state, and ZIP format, so locations can be used in any region.

Locations can also be used to target supported features, including some plugins.

A Location is only organizational information. Putting two screens in the same Location does not mean they share the same network or hardware capabilities.

When a screen moves to another building or room, update its Location from the screen details page.
