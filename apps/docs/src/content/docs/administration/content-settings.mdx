---
title: Content and playback settings
description: Set organization defaults for playback, websites, media, and scheduling.
---

Open **Settings** to change defaults that Players use when content does not set its own value.

## Playback

Playback defaults include volume, fit mode, image duration, transition, audio, and whether supported content resumes after a Player restart.

A Playlist item set to **Use Player defaults** follows these settings. If the item has its own value, that item keeps its own setting.

## Websites

Website settings control things such as timeouts and browser storage for remote content.

Settings that only apply when the Player starts take effect the next time the Player starts. They do not clear a website in the middle of playback.

## Media and schedules

Media settings control organization defaults and limits for stored or prepared media.

Schedule timing still comes from each Schedule's own dates, times, timezone, priority, and targets.

## Overrides

Player settings are resolved in this order:

1. screen override;
2. Display Group policy;
3. organization default;
4. Tilecast built-in default.

See [Set Player policies](../player-policies/) for Display Group and screen overrides.
