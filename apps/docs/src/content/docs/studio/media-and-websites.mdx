Media and websites are the content you place in a Playlist or Layout. Choose by what the screen should show.

Media is prepared on Tilecast Server and stored on each Player, so it can keep playing if the network drops. A website is remote content, so the Player needs its own network connection to show it.

When an upload never becomes ready, or a website stays blank, see [Media uploads and processing](../../troubleshooting/media/) and [Websites](../../troubleshooting/websites/).

When your content is ready, [build a Playlist](../../playlists/) or [build a Layout](../../layouts/) to put it on a screen.
