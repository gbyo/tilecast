A **Widget** decides how information looks on a screen. A **Data Source** holds the information. Because the two are separate, one Data Source can feed several Widgets on different displays.

To fill a Manual Table from a system that owns the data, such as a room booking or menu system, see [Replace Manual Table rows](../../integrations/manual-table/). To see every Widget and Data Source definition that ships with your Tilecast version, see the [content definition reference](../../reference/content-definitions/).

Use a Widget in a [Playlist](../../playlists/) or a [Layout](../../layouts/) to put it on a screen.
