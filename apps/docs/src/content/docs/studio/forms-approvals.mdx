title: Form approvals
description: Review submitted Form records, request changes, and approve records for signage workflows.
---

The central **Approvals** inbox is for Form records. It is separate from the presentation-content submission inbox used by Playlists, Layouts, and Campaigns.

An account sees review work only for Forms where its granted capabilities allow it.

## Review a record

Open a submitted record and use the transitions the server returns for your account and that record's current state.

The default workflow includes:

- **Approve**: move the record to the approved state.
- **Request changes**: return it to the submitter with a required review note.
- **Reject**: move it to the final rejected state.

A submitter can edit and resubmit a record after changes are requested. The server validates permissions and workflow transitions; the browser does not invent which actions are allowed.

A Form View that feeds signage must include an output-eligible state such as approved before the record can appear in that view.

For Playlist, Layout, and Campaign review, use [Content submissions](../content-submissions/).
