**Forms** is a built-in Tilecast plugin. An Owner or Administrator installs it from **Operations** > **Plugins**.

After it is installed, people with content-management permission can create and manage forms under **Plugins** > **Forms**.

Form data does not appear in the normal external **Data Sources** library.

## Create a form

A form has fields and a review workflow.

The default workflow includes draft, submitted, changes requested, approved, rejected, and expired states.

Publishing a new form version does not rewrite older submissions. Existing records keep the form version they were created with.

## Submit a form

People use **My Forms** to see forms they can access and their own submissions.

A submitter can edit a record while its current state allows editing, then submit or resubmit it.

If a reviewer requests changes, the reviewer note appears with the submission so it can be updated and sent again.

## Use approved records in signage

A Form View chooses which records and fields can be used by Tilecast content.

Approved records can then feed Widgets and Layouts like other structured data in Tilecast.

See [Form approvals](../forms-approvals/) for the review workflow.
