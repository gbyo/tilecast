## Repository layout

<FileTree>

- tilecast/
  - apps/ Product applications.
    - server/ Go server, HTTP API, and database migrations.
    - cli/ Remote tilecast CLI and its MCP server.
    - dashboard/ React and TypeScript management app, Tilecast Studio.
    - player-android/ Kotlin and Jetpack Compose Player for Android TV devices.
    - player-linux/ Electron Player for Linux kiosk devices.
    - edge/ Tilecast Edge, the new Linux player: a Rust daemon, a WPE WebKit renderer, update and migration helpers, and a small user-session bridge.
    - docs/ Astro and Starlight public documentation site.
  - plugins/ Bundled plugins, one directory each.
  - widgets/ Core Widgets, one directory each.
  - packages/ Shared design tokens, the API client, application contracts, and the plugin and Widget SDKs.
  - deploy/ Docker deployment and optional network integrations.
  - docs/ Engineering references, API descriptions, and implementation contracts.

</FileTree>

The Server is a modular monolith backed by one PostgreSQL database and one organization per installation. Studio consumes the generated OpenAPI contract through typed transport and API domain modules. Android uses a native Player; Electron and WPE hosts share the Player Runtime renderer. Read the living [architecture reference](https://github.com/gbyo/tilecast/blob/main/docs/architecture.md) for ownership boundaries and links to the exact domain contracts.
